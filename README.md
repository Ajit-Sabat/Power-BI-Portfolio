### 🛒 3. Olist E-Commerce Analytics Dashboard

<div align="center">

![Olist Dashboard](Olist%20Ecommerce%20Dashboard/Executive.png)

</div>

**📌 Business Objective:**  
Deliver an end-to-end data analytics pipeline and interactive Power BI dashboard for Olist's Brazilian e-commerce dataset, integrating data engineering, SQL modeling, and BI storytelling to uncover insights on sales, delivery performance, and customer retention.

**🎯 Key Insights:**
- Sales performance trends across product categories and regions
- Delivery efficiency metrics and logistics optimization opportunities
- Customer segmentation and retention analysis
- Revenue forecasting and growth patterns
- Payment method preferences and order fulfillment rates

**🛠️ Technical Implementation:**
- **Data Engineering:** Python-based ETL pipeline using Pandas and NumPy for data cleaning and preparation
- **Database Design:** MySQL star schema implementation with optimized indexing
- **Data Modeling:** Designed dimensional model with fact and dimension tables
- **Visualization:** Power BI dashboard with advanced DAX measures and KPIs
- **Analytics:** Customer cohort analysis, RFM segmentation, and delivery performance metrics

**📂 Technologies:** Power BI | Python (Pandas, NumPy) | MySQL | DAX | Power Query

## 🚀 How to Use This Portfolio

### 📥 Viewing the Dashboards

1. **Clone this repository:**
   ```bash
   git clone https://github.com/Ajit-Sabat/Power-BI-Portfolio.git
   ```

2. **Navigate to project folder:**
   ```bash
   cd Power-BI-Portfolio
   ```

3. **Open the .pbix files:**
   - Download and install [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free)
   - Navigate to the specific project folder
   - Double-click the `.pbix` file to open in Power BI Desktop
   - Explore interactive visualizations and insights

### 🔧 For Python-Based Projects (Olist E-Commerce)

```bash
cd "Olist Ecommerce Dashboard"
pip install pandas numpy mysql-connector-python
python data_processing.py
```
